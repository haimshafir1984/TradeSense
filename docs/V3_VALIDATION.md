# בדיקת v3 — 9 בספטמבר 2026

## בוצע

- `npm run build`: הצלחה, Vite 7.3.6.
- `npm test --workspace server`: 308 בדיקות עברו, ללא כישלונות. בדיקות v3 כוללות סריקה מלאה עם ספקים מדומים, מניעת שכפול, מעקב בלי דפדפן, הגנת API, SIP יומי ללא נר היום, כשל HTTP חלקי שאינו מסומן כהצלחה מלאה, בחירת round-robin ורוטציה, דירוג VWAP לפי RVOL קיים במטמון IEX, אי־שמירת daily cache חלקי כסימן תקין, רענון intraday מלא ביום חדש, ואבחון שיטות יום בלי דרישת MA200 גלובלית.
- `npm run autopilot:compare-selection --workspace server`: הצלחה. זהו סקריפט read-only עם קלט סינתטי; הוא דיווח 25 מניות בבחירה הישנה מול 80 בבחירה החדשה, 55 מחוץ ל־25 הישנות, ופיזור לפי אסטרטגיה. הסקריפט אינו יוצר איתותים ואינו שולח התראות.
- `git diff --check`: הצלחה. הופיעו רק אזהרות CRLF רגילות של Windows, ללא שגיאות whitespace.
- v3.1 ממומש בקוד: מאגר יומי עד 2,000 מניות לפי Alpaca assets + SIP, בחירת עד 120 מועמדות, מטמון daily/intraday ב־SQLite, אבחון אישי וציבורי, ומניות במעקב במסך "הזדמנויות היום".
- לאחר סקירת GPT-6 תוקנו נקודות כיסוי נוספות: סימולים שנכשלו בבקשת history לא נשמרים כמטמון תקין, מטמון IEX תוך־יומי מחויב לתאריך הסשן הנוכחי, snapshots נרעננים שוב אחרי הורדת ההיסטוריה לפני איתות, חדשות Gap נבדקות רק אחרי ששאר תנאי הטריגר מוכנים, ומועמדות בדשבורד מסוננות מחדש לפי הגדרות המשתמש בזמן התגובה.

## בוצע קודם ונשאר רלוונטי

- `npm audit --omit=dev`: אפס חולשות מדווחות לאחר עדכון תלויות תואם. גם `npm audit fix` הסתיים עם אפס חולשות.
- דפדפן Playwright: דף אמיתי מחובר ל־API המקומי; מחירי הזדמנויות אינם מומצאים כשהשוק סגור. חיבור נתוני שוק מוגדר, heartbeat תקין וללא שגיאת מנוע בזמן הבדיקה.
- תצוגת 390×844 ללא גלילה אופקית; תצוגת מחשב 1440×1000.
- מסד בדיקה נפרד ב־`output/playwright/fixture.sqlite`: דיווח מחיר לא תקין מציג הודעה בתוך החלון; קניית 0.2 מניות במחיר 100 ומכירה ב־104 מניבה $0.80 בתוצאות האישיות בלבד, כשהסימולציה נותרת ריקה. שמירת הון בדיקה $500 אומתה מול השרת.
- לאחר הבדיקה הוחזר הדפדפן ל־API האמיתי. ההון המקומי נותר $100 וללא דיווחי עסקאות שנוצרו על ידי הבדיקה. קובץ התיק הישן לא שונה.

## טרם אומת

אין backtest היסטורי ל־v3.1, ואין כאן הוכחה לרווחיות. עוד לא נצברה מדידת forward בשוק פתוח לגרסה זו. נתוני IEX חלקיים; ביצוע OHLC סימולטיבי אינו מחיר ביצוע ב־Blink.

לא בוצעה פריסה לענן במסגרת הבנייה המקומית ולא נבדק Render לאחר שינוי v3.1. יש להגדיר את סביבת הייצור לפי [המפרט](SPEC_V3_AUTOPILOT.md), לבדוק שמירה לאחר ריסטארט בענן ולהשלים בדיקת Push במכשיר המשתמש. ההרשאות והמסירה בטלפון אינן ניתנות לאישור על סמך בדיקת דפדפן מקומית בלבד.

לא בוצעה בדיקה חיה בזמן מסחר מול כל המאגר החדש. סקריפט ההשוואה הנוכחי משתמש בקלט סינתטי כדי לבדוק את המנגנון, לא כדי להבטיח כמות איתותים או רווחיות.
